# Organization_Management 

Organization Management or O.M is website that allow staff to monitor the organization and their own division, like upcoming meeting, their programs within each division among other things and then the player of each division they can see any upcoming event that their division participating in, upcoming meeting and most importantly their achievement.

# Features 

Our website has specific features that is exclusive to each user job in the organization, like player with their own dashboard with stuff related to tournament and staff with their own dashboard related to more organizational stuff like meeting and other administrative task.

For players there are :
- Scrim schedule
- Upcoming tournament date
- Past tournament wins

For staff there are :
- List of active program
- All division in the organization
- Adding another program
- Creating new task
- Rate of absence from total meetings
- Number of active members in the organization
- Adding/removing member
- See past attendance list and download the data
